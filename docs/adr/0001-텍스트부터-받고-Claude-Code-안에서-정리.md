# 0001. 텍스트부터 받고 Claude Code 안에서 정리한다

- 상태: 제안(요구 확인 대기)
- 날짜: 2026-11-19

## 결정
- 음성 녹음 · 인식은 앱 밖(유니브)에서 한다. 앱 입력은 `[분:초] 문장` 형식 텍스트다.
- 정리는 Claude Code 안의 명령(스킬)으로 한다. Claude API 키는 쓰지 않는다.

## 근거
- 비용 상한이 추가 0원이다(요구 Q4).
- 사용자가 이미 유니브로 텍스트를 만들고 있다(요구 Q2 · O1).
- 음성을 다루지 않으면 만들 양이 크게 준다.

## 기각한 대안
- 앱이 음성 인식까지 함(내 PC Whisper · 유료 API): 설치가 어렵거나 돈이 든다.
- Claude API로 파이썬 앱을 만듦: 1시간 회의 1건에 Haiku 5.5 약 5원(추정)이지만 선결제와 키 관리가 필요하다.

## 결과
- 다른 사람이 직접 돌려 볼 수는 없다. 포트폴리오는 시연 영상과 결과 파일로 보여 준다.
- 입사 후 팀 공유가 필요하면 새 ADR로 API 방식을 다시 검토한다.
