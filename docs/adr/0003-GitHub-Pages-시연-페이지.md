# 0003. GitHub Pages 시연 페이지를 둔다

- 상태: 승인(2026-11-19)
- 날짜: 2026-11-19
- 대체: ADR 0001 '결과'의 "다른 사람이 직접 돌려 볼 수는 없다"

## 결정
- 저장소를 공개하고, 저장소 맨 위 `index.html`을 GitHub Pages로 연다. 주소: https://githubleejungah.github.io/meeting-actions/
- 페이지의 AI 값(초안 · 위험도 제안 · 되물을 질문)은 내 PC 도구로 미리 돌린 결과를 담고, '미리 돌린 결과'라고 표시한다.
- 방문자가 고르는 위험도 확정 · 판정 · 상태와 그에 따른 점검표 정렬 · 지연 표시 · 이름 가리기는 브라우저에서 `src/rules.json`과 같은 규칙으로 실제로 돈다.

## 근거
- 지원 서류에 넣을 링크가 필요하다(요구 Q16).
- 비용 0원(요구 Q4). 페이지에 API 키가 없어 남용 위험이 없다.
- 채용 담당자가 설치 없이 '사람이 판정한다'를 직접 눌러 본다.

## 기각한 대안
- 시연 영상만: 링크는 되지만 눌러 볼 수 없다.
- 실시간 AI 웹앱: API 요금이 나가고, 키를 숨길 서버가 필요하다.

## 결과
- 저장소 전체가 공개된다. 실제 데이터는 저장소 밖에 두는 규칙(AC-10)이 더 중요해진다.
- 시연 페이지와 내 PC 도구의 규칙이 어긋나지 않도록 같은 `rules.json`을 읽는다(AC-50).
