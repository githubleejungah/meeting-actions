# 0002. 현장 이슈 접수 · 판정을 같은 대장에 합친다

- 상태: 제안(요구 확인 대기)
- 날짜: 2026-11-19

## 결정
- 회의 할 일과 현장 이슈를 엑셀 파일 하나의 두 시트('할 일' 11칸 · '이슈' 16칸)에 쌓는다.
- 두 시트의 위험도를 A(안전 · 작업 중단) / B(기능 저하 · 시즌 영향) / C(불편 · 표시 오류)로 통일한다.
- AI는 초안과 위험도 '제안'만 한다. 위험도 확정 · 판정(반영 / 조건부 반영 / 보류) · 상태 · 종결은 사람이 한다.

## 근거
- 사용자 결정 "네 합치고 해주세요"(요구 1-2절).
- 회의에서 이슈를 판정하고 할 일이 나오는 흐름을 한 대장에서 보여 줄 수 있다(요구 F8).
- 사용자의 PM 업무 샘플(이슈 관리표 · 우선순위 기준)과 같은 양식이다(요구 D1).

## 기각한 대안
- 앱을 두 개로 나눔: 회의와 이슈를 잇는 '관련 이슈 번호'를 따로 맞춰야 한다.
- 한 시트에 섞음: 칸이 달라 빈칸이 많아진다(요구 F6).
- 위험도 상/중/하 유지: 이슈의 A/B/C와 이름이 달라 점검 때 헷갈린다.

## 결과
- 요구 Q6 · Q8의 답이 바뀌었다(요구 8절).
- 사진 분석 · 소급 조치 · 주간 보고서는 범위 밖이다.
